# AwwO Local · AwwO 本地版

Installers for AwwO Local: AwwO's own database, API, web app and agents on your own computer, for you alone, with your
own model keys. This repository holds only the releases: download the newest from
[Releases](https://github.com/Clawhunt-Site/awwo-local/releases).

AwwO 本地版的安装包：在你自己的电脑上运行 AwwO 自己的数据库、API、网页和执行服务，只供你一人使用，用你自己的模型 Key。
这个仓库只放发布的安装包，最新版本见 [Releases](https://github.com/Clawhunt-Site/awwo-local/releases)。

- **Windows 10 and 11 (x64)**: `AwwO-Local_<version>_x64-setup.exe`, with `SHA256SUMS.txt` to check it. Each release's
  notes say how to install it and what it does not include yet.
  Windows 10 和 11（x64）：`AwwO-Local_<版本>_x64-setup.exe`，可用 `SHA256SUMS.txt` 校验。每个版本的说明写了安装方法和暂不包含的功能。
- **macOS**: later. / macOS 版稍后推出。

More about AwwO: [clawhunt.store/awwo](https://clawhunt.store/awwo). / 了解 AwwO：[clawhunt.store/awwo](https://clawhunt.store/awwo)。
