# AwwO Local · AwwO 本地版

Installers for AwwO Local: AwwO's own database, API, web app and agents on your own computer, for you alone, with your
own model keys. This repository holds only the releases: download the newest from
[Releases](https://github.com/Clawhunt-Site/awwo-local/releases).

AwwO 本地版的安装包：在你自己的电脑上运行 AwwO 自己的数据库、API、网页和执行服务，只供你一人使用，用你自己的模型 Key。
这个仓库只放发布的安装包，最新版本见 [Releases](https://github.com/Clawhunt-Site/awwo-local/releases)。

- **Windows 10 and 11 (x64)**: [`AwwO-Local_x64-setup.exe`](https://github.com/Clawhunt-Site/awwo-local/releases/latest/download/AwwO-Local_x64-setup.exe),
  always the newest version, with `SHA256SUMS.txt` to check it. Each release's notes say how to install it and what it
  does not include yet.
  Windows 10 和 11（x64）：[`AwwO-Local_x64-setup.exe`](https://github.com/Clawhunt-Site/awwo-local/releases/latest/download/AwwO-Local_x64-setup.exe)，始终是最新版本，可用 `SHA256SUMS.txt` 校验。每个版本的说明写了安装方法和暂不包含的功能。
- **macOS 14 or later (Apple silicon)**: AwwO for Mac, which also opens your online AwwO workspace. The newest is
  [0.10.3](https://github.com/Clawhunt-Site/awwo-local/releases/tag/local-macos-v0.10.3). Its releases have tags that
  begin with `local-macos-v` and are never marked Latest, so that the Windows link above keeps working.
  macOS 14 或更新版本（Apple 芯片）：AwwO for Mac，也能打开你的线上 AwwO 工作区。最新版本是 [0.10.3](https://github.com/Clawhunt-Site/awwo-local/releases/tag/local-macos-v0.10.3)。Mac 版的标签以 `local-macos-v` 开头，不会标为 Latest，这样上面的 Windows 链接才始终有效。
